# Wansan Studio 更新日志 (v0.6.0)  -- Insight, Power & Reach


#### 1. AI 业务洞察与“视觉锚定” (Visual Anchoring)

为了保障极致的数据隐私，AI 业务洞察功能现在完全由**用户主动发起**。

* **隐私机制**：仅在用户触发洞察时，系统才会提取当前图表的聚合特征（非原始明细数据）发送至 LLM。
* **视觉锚定 (Visual Anchoring)**：引入了结论与图表的联动能力，悬停 AI 生成的文字结论，图表中对应的元素将实时高亮，方便用户快速核实数据证据。

#### 2. 专业级 SQL 实验室

我用 **Monaco Editor** 彻底重做了 SQL 开发环境，为需要深度控制数据的专业人士提供生产级体验。

* **指令化操作**：支持通过 **`/` 命令** 直接执行 SQL。运行结果可一键转化为图表卡片，实现了“写 SQL 即写报表”的高效流转。
* **Schema 感知**：编辑器具备本地 DuckDB 库表感应能力，提供智能补全、语法高亮及自动双引号处理，确保复杂 SQL 的编写效率。
* **审计与掌控**：用户可以随时审计 AI 生成的每一行代码，并在实验室中进行手动优化与执行预览。

#### 3. “流式报告”模式与单文件分发

相较于之前版本的网格看板，v0.6.0 推出了全新的**流式报告模式 (Flow Report Mode)**。

* **叙事结构**：支持 Markdown 富文本与图表联动，通过纵向流式排版让数据分析过程具备更强的叙事性。
* **Hydration Pack 导出**：支持一键导出为独立的 `.html` 网页文件。
* **实现细节**：将 React 运行时、UI 组件 以及数据 Snapshot 封装在单文件中，利用浏览器端的 Hydration 确保导出的报告仍具备 Tooltip 和联动交互能力。为了平衡导出文件的体积，ECharts 引用了公共 CDN 资源，如果您有完全离线环境的需求，欢迎向我反馈。
