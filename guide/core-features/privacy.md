# 隐私与安全协议

在 Wansan 中，您的数据隐私是我们的最高优先级。

## 核心机制：Schema-Only

不同于云端 BI 工具需要您上传整个数据集，Wansan 采用 **Schema-Only (仅表结构)** 协议：

1.  **本地分析**：当您导入文件时，Wansan 使用本地集成的分析引擎对数据进行索引和计算。
2.  **元数据提取**：系统仅提取表名、列名和数据类型（例如：`日期`, `销售额`, `地区`）。
3.  **AI 交互**：只有这些元数据会被发送给 AI (如 DeepSeek 或 OpenAI)，用于生成分析逻辑和 SQL 语句。
4.  **原始数据不离境**：您的每一行原始记录都始终保存在您的个人电脑上，绝不会发送给 AI。

## 安全建议

*   **API Key**：请妥善保管您的 AI 服务 API Key。Wansan 会将其加密保存在您的本地系统安全存储中。
