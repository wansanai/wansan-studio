# 欢迎使用 Wansan Studio

Wansan Studio 是一款配合 AI 使用的本地数据分析工具。它能帮助您通过对话的方式，直接分析电脑上的表格文件，并生成专业的分析报告。

### 名字背后的寓意
“万三” 取自明代传奇巨商 **沈万三 (Shen Wansan)**。传说他拥有一只“聚宝盆”，能让财富生生不息。

在数字时代，数据就是新的财富。我们希望 Wansan Studio 能成为您桌面上现代版的“聚宝盆” —— 通过精准的本地计算，挖掘每一行数据背后的商业价值，同时像守财一样守护您的隐私。
